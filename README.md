# Inventory Management System

A comprehensive application designed to streamline stock tracking, order fulfillment, and warehouse operations. Built to eliminate manual spreadsheet errors, this system provides real-time visibility into product quantities, supplier details, and inventory movements.

## Key Features
* **Real-Time Stock Tracking:** Monitor incoming and outgoing inventory with automatic quantity updates.
* **Low-Stock Alerts:** Receive automated notifications when items fall below customizable reorder thresholds.
* **Product & Category Management:** Organize items by SKU, category, price, and supplier.
* **Order & Supplier Tracking:** Manage purchase orders, sales orders, and vendor contact records in one place.
* **Reporting & Analytics:** Export inventory summaries and track stock valuation over time.
